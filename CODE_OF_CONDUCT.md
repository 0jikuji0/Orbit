# Code de conduite

Ce projet adopte le [Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé : soyez respectueux, bienveillant et constructif. Le harcèlement et les comportements discriminatoires ne sont pas tolérés.

Les manquements peuvent être signalés de façon privée aux mainteneurs via l'onglet **Security** du dépôt ou par message privé.
